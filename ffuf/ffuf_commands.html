Sintaxis básica (FFUF)
ffuf -u URL -w wordlistPara qué sirve: Fuerza bruta de directorios/archivos en un servidor web. La URL debe contener FUZZ donde se insertará cada palabra de la wordlist.
-u URL objetivo · -w wordlist a usar
ffuf -u http://target/FUZZ -w /usr/share/wordlists/dirb/common.txtPara qué sirve: Fuerza bruta básica de directorios. Sustituye FUZZ por cada palabra de la wordlist common.txt.
/usr/share/wordlists/dirb/common.txt wordlist por defecto en Kali
ffuf -u http://target/?param=FUZZ -w /usr/share/wordlists/raft-small-words.txtPara qué sirve: Fuerza bruta de parámetros GET. Prueba cada palabra como valor del parámetro.
FUZZ se sustituye en la posición del parámetro
ffuf -hPara qué sirve: Muestra ayuda completa con todas las opciones disponibles.
ffuf -h lista completa de flags
Fuerza bruta de directorios y archivos
ffuf -u http://target/FUZZ -w wordlist.txt -mc 200Para qué sirve: Busca directorios que devuelvan status 200 (OK). Filtra por código de respuesta.
-mc 200 match status code 200
ffuf -u http://target/FUZZ -w wordlist.txt -mc 200,301,302Para qué sirve: Busca directorios con status 200, 301 y 302 (redirecciones).
-mc 200,301,302 match múltiples códigos
ffuf -u http://target/FUZZ -w wordlist.txt -fc 404Para qué sirve: Filtra y oculta las respuestas con status 404 (Not Found).
-fc 404 filter status code 404
ffuf -u http://target/FUZZ -w wordlist.txt -e .php,.html,.txtPara qué sirve: Añade extensiones a cada palabra de la wordlist. PruebaFUZZ.php, FUZZ.html, FUZZ.txt.
-e extensiones a probar
ffuf -u http://target/FUZZ -w wordlist.txt -recursion -recursion-depth 2Para qué sirve: Busca directorios recursivamente. Si encuentra uno, busca dentro de él.
-recursion activar recursión · -recursion-depth profundidad máxima
Fuerza bruta de parámetros
ffuf -u http://target/?FUZZ=test -w wordlist.txt -mc 200Para qué sirve: Descubre parámetros GET ocultos. Prueba cada palabra como nombre de parámetro.
FUZZ se sustituye en la posición del parámetro
ffuf -u http://target/ -X POST -d 'FUZZ=test' -w wordlist.txt -mc 200Para qué sirve: Descubre parámetros POST. Envía cada palabra como nombre del campo.
-X POST método HTTP · -d datos POST
ffuf -u http://target/?id=FUZZ -w /usr/share/seclists/Discovery/Web-Content/burp-parameter-names.txt -mc 200Para qué sirve: Fuzzing de valores de parámetros. Prueba diferentes valores en el parámetro id.
-w wordlist de parámetros comunes
Wordlists recomendadas
/usr/share/wordlists/dirb/common.txtPara qué sirve: Wordlist básica de directorios comunes. Buen punto de partida para fuzzing rápido.
~4600 palabras · rápida pero limitada
/usr/share/wordlists/dirbuster/directory-list-2.3-medium.txtPara qué sirve: Wordlist media de DirBuster. Más completa que common.txt.
~220000 palabras · buen equilibrio velocidad/cobertura
/usr/share/seclists/Discovery/Web-Content/raft-small-directories.txtPara qué sirve: Raft small - directorios comunes encontrados en producción.
~6200 palabras · resultados reales
/usr/share/seclists/Discovery/Web-Content/raft-large-directories.txtPara qué sirve: Raft large - la más completa para fuzzing exhaustivo.
~62000 palabras · lenta pero cubre todo
/usr/share/seclists/Discovery/Web-Content/common.txtPara qué sirve: Seclists common - alternativa a dirb common, actualizada.
~4700 palabras · buena para empezar
/usr/share/seclists/Discovery/Web-Content/api/api-endpoints.txtPara qué sirve: Wordlist específica para descubrir endpoints de APIs REST.
~2400 palabras · enfocada en APIs
Opciones de wordlists
ffuf -u URL -w wordlist.txt:FUZZPara qué sirve: Asigna un nombre específico a la wordlist. Útil cuando usas múltiples wordlists.
:FUZZ nombre del placeholder
ffuf -u URL -w wordlist1.txt:FUZZ1 -w wordlist2.txt:FUZZ2Para qué sirve: Usa dos wordlists simultáneamente. Cada una con su placeholder.
-w se puede repetir para múltiples wordlists
ffuf -u http://target/FUZZ -w wordlist.txt -icPara qué sirve: Ignora comentarios en la wordlist (líneas que empiezan por #).
-ic ignore comments
ffuf -u URL -w wordlist.txt -fs 4242Para qué sirve: Filtra por tamaño de respuesta. Oculta respuestas de 4242 bytes.
-fs filter size
Filtros por código de estado
-mc 200Para qué sirve: Muestra solo respuestas con status 200 (OK). El filtro más básico y común.
-mc match code
-mc 200,301,302,403Para qué sirve: Muestra respuestas con múltiples códigos de estado.
-mc acepta lista separada por comas
-fc 404Para qué sirve: Oculta respuestas con status 404 (Not Found). Elimina el ruido.
-fc filter code
-fc 400,401,403,404,500,502,503Para qué sirve: Oculta todos los códigos de error comunes. Filtra agresivamente.
-fc filter code - múltiples valores
-acPara qué sirve: Auto-calibra los filtros. Detecta automáticamente el código de error más frecuente y lo filtra.
-ac auto-calibrate
Filtros por tamaño de respuesta
-fs 0Para qué sirve: Oculta respuestas vacías (0 bytes). Útil para eliminar endpoints que no devuelven contenido.
-fs filter size
-fs 4242Para qué sirve: Oculta todas las respuestas de 4242 bytes. Para filtrar un tamaño específico.
-fs filter size - valor exacto
-fs 400-500Para qué sirve: Oculta respuestas con tamaño entre 400 y 500 bytes.
-fs filter size - rango
-ms 100-200Para qué sirve: Muestra solo respuestas con tamaño entre 100 y 200 bytes.
-ms match size
-mc 200 -fs 0Para qué sirve: Combinación: muestra solo 200 pero oculta las respuestas vacías.
-mc + -fs se pueden combinar
Filtros por palabras y líneas
-fw 10Para qué sirve: Oculta respuestas que contengan exactamente 10 palabras.
-fw filter words
-fl 5Para qué sirve: Oculta respuestas que contengan exactamente 5 líneas.
-fl filter lines
-mw 50Para qué sirve: Muestra solo respuestas con 50 palabras.
-mw match words
-ml 3Para qué sirve: Muestra solo respuestas con 3 líneas.
-ml match lines
-ac -fs 0Para qué sirve: Auto-calibra + filtra vacías. Combo potente para reducir ruido automáticamente.
-ac auto-calibrate · -fs 0 filter size 0
Autenticación y headers
ffuf -u URL -w wordlist.txt -H "Authorization: Bearer TOKEN"Para qué sirve: Envía un header de autenticación con cada petición. Útil para APIs protegidas.
-H añadir header
ffuf -u URL -w wordlist.txt -H "Cookie: session=abc123"Para qué sirve: Envía una cookie específica. Para fuzzing de áreas autenticadas.
-H header personalizado
ffuf -u URL -w wordlist.txt -X POST -d 'user=admin&pass=FUZZ'Para qué sirve: Fuerza bruta de contraseñas via POST. FUZZ se sustituye en el campo pass.
-X POST método · -d datos
ffuf -u URL -w wordlist.txt -H "Content-Type: application/json" -X POST -d '{"user":"admin","pass":"FUZZ"}'Para qué sirve: Fuerza bruta con JSON body. Útil para APIs REST.
-H "Content-Type: application/json" tipo de contenido
Proxy y headers personalizados
ffuf -u URL -w wordlist.txt -x http://127.0.0.1:8080Para qué sirve: Envía todo el tráfico por un proxy (Burp Suite). Para interceptar y analizar.
-x proxy URL
ffuf -u URL -w wordlist.txt -H "X-Forwarded-For: 127.0.0.1"Para qué sirve: Inyecta header X-Forwarded-For. Para bypass de restricciones IP.
-H header personalizado
ffuf -u URL -w wordlist.txt -t 50Para qué sirve: Ejecuta 50 hilos simultáneos. Por defecto usa 40.
-t threads (hilos)
ffuf -u URL -w wordlist.txt -p 0.5Para qué sirve: Añade delay de 0.5 segundos entre peticiones. Para evitar rate limiting.
-p delay (segundos)
ffuf -u URL -w wordlist.txt -rate 100Para qué sirve: Limita a 100 peticiones por segundo.
-rate peticiones por segundo
Recursión y output
ffuf -u URL/FUZZ -w wordlist.txt -recursion -recursion-depth 2Para qué sirve: Busca recursivamente en directorios encontrados. Profundidad máxima de 2 niveles.
-recursion activar · -recursion-depth niveles
ffuf -u URL/FUZZ -w wordlist.txt -o resultados.json -of jsonPara qué sirve: Guarda los resultados en formato JSON.
-o archivo de salida · -of formato (json, csv, html, md)
ffuf -u URL/FUZZ -w wordlist.txt -o report.html -of htmlPara qué sirve: Genera un reporte HTML con los resultados. Fácil de revisar después.
-of html formato HTML
ffuf -u URL/FUZZ -w wordlist.txt -vPara qué sirve: Modo verbose. Muestra más detalles de cada petición.
-v verbose
ffuf -u URL/FUZZ -w wordlist.txt -sPara qué sirve: Modo silencioso. Solo muestra resultados, sin barra de progreso.
-s silent mode
