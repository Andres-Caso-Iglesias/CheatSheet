Comandos Nmap

Referencia interactiva de comandos Nmap para escaneo de red

Descubrimiento de hosts (Nmap)
nmap -sn <target>Para qué sirve: Ping scan — descubre hosts sin escanear puertos.
-sn solo ping · target IP/rango/CIDR
nmap -sP <target>Para qué sirve: Alias de -sn (versiones antiguas).
-sP ping scan legacy
nmap -sL <target>Para qué sirve: Lista de escaneo — resuelve DNS sin enviar paquetes.
-sL solo listar · -n sin DNS
nmap -PR <target>Para qué sirve: ARP ping scan (red local).
-PR ARP ping · más rápido en LAN
nmap -PE -PP -PM <target>Para qué sirve: Tipos de ping ICMP.
-PE echo · -PP timestamp · -PM netmask
nmap -PS<puertos> <target>Para qué sirve: TCP SYN ping scan.
-PS80,443 puertos SYN · -PA ACK ping · -PU UDP ping
Escaneo de puertos (Nmap)
nmap <target>Para qué sirve: Escaneo por defecto — 1000 puertos TCP más comunes.
target IP/hostname
nmap -p <puertos> <target>Para qué sirve: Escanear puertos específicos.
-p 80 un puerto · -p 80-443 rango · -p 80,443,8080 lista
nmap -p- <target>Para qué sirve: Escanear TODOS los puertos (1-65535).
-p- todos los puertos · lento pero completo
nmap -sS <target>Para qué sirve: TCP SYN scan (half-open) — el más común.
-sS SYN scan · no completa handshake · más rápido
nmap -sT <target>Para qué sirve: TCP Connect scan — completa handshake.
-sT connect scan · sin privilegios root
nmap -sU <target>Para qué sirve: UDP scan — descubre servicios UDP.
-sU UDP scan · lento · -sS -sU combinado
nmap --top-ports <n> <target>Para qué sirve: Escanear los n puertos más comunes.
--top-ports 100 100 más usados · --top-ports 1000 default
Detección de servicios y OS (Nmap)
nmap -sV <target>Para qué sirve: Detección de versión de servicios.
-sV version scan · --version-intensity <n> 0-9
nmap -O <target>Para qué sirve: Detección de sistema operativo.
-O OS detection · requiere root
nmap -A <target>Para qué sirve: Escaneo agresivo — OS + versiones + scripts + traceroute.
-A agresivo · combina -sV -O -sC --traceroute
nmap -sV --version-all <target>Para qué sirve: Máxima intensidad de detección de versiones.
--version-all todas las pruebas · --version-trace debug
nmap --traceroute <target>Para qué sirve: Traceroute al objetivo.
--traceroute mostrar ruta · usa TTL
Escaneo stealth y evasión (Nmap)
nmap -sN <target>Para qué sirve: NULL scan — sin flags TCP.
-sN NULL scan · evade firewalls simples
nmap -sF <target>Para qué sirve: FIN scan — solo flag FIN.
-sF FIN scan · similar a NULL
nmap -sX <target>Para qué sirve: Xmas scan — flags FIN+PSH+URG.
-sX Xmas tree scan
nmap -sA <target>Para qué sirve: ACK scan — mapear reglas de firewall.
-sA ACK scan · no descubre puertos abiertos
nmap -sW <target>Para qué sirve: Window scan — detecta puertos abiertos vía window size.
-sW window scan
nmap --scanflags <flags> <target>Para qué sirve: Flags TCP personalizados.
--scanflags URGPSHACK flags custom · URG ACK FIN
nmap -D <decoys> <target>Para qué sirve: Decoy scan — IPs falsas para confundir.
-D RND:10 10 decoys aleatorios · -D IP1,IP2,ME
nmap -f <target>Para qué sirve: Fragmentación de paquetes.
-f 8 bytes · -ff 16 bytes · -mtu <n> MTU custom
Evasión de firewall e IDS (Nmap)
nmap --source-port <puerto> <target>Para qué sirve: Usar puerto fuente específico.
--source-port 53 DNS · --source-port 80 HTTP
nmap --data-length <n> <target>Para qué sirve: Añadir datos aleatorios a paquetes.
--data-length 25 payload random · evasión IDS
nmap --randomize-hosts <target>Para qué sirve: Aleatorizar orden de hosts.
--randomize-hosts orden random · no secuencial
nmap --spoof-mac <mac> <target>Para qué sirve: Spoofing de dirección MAC.
--spoof-mac 0 MAC aleatoria · --spoof-mac AA:BB:CC:DD:EE:FF
nmap --badsum <target>Para qué sirve: Checksums inválidos — detectar firewalls/IPS.
--badsum checksums rotos · respuestas revelan IPS
nmap -g <puerto> <target>Para qué sirve: Puerto fuente (alias de --source-port).
-g 53 puerto fuente 53
Control de rendimiento (Nmap)
nmap -T<0-5> <target>Para qué sirve: Template de timing.
-T0 paranoico · -T3 normal · -T4 agresivo · -T5 insane
nmap --min-rate <n> <target>Para qué sirve: Velocidad mínima de paquetes/seg.
--min-rate 1000 1000 pps mínimo
nmap --max-rate <n> <target>Para qué sirve: Velocidad máxima de paquetes/seg.
--max-rate 100 máximo 100 pps
nmap --min-parallelism <n> <target>Para qué sirve: Sondeos paralelos mínimos.
--min-parallelism 100 100 sondeos simultáneos
nmap --host-timeout <tiempo> <target>Para qué sirve: Tiempo máximo por host.
--host-timeout 30m 30 minutos · --host-timeout 1h
nmap -iL <archivo>Para qué sirve: Escanear hosts desde archivo.
-iL targets.txt lista de IPs · un host por línea
Scripts de vulnerabilidades (NSE)
nmap --script vuln <target>Para qué sirve: Corre ~200 scripts de la categoría "vuln" de una vez. Útil para auditorías completas, pero lento.
-sV recomendado con detección de versión · -p- todos los puertos
nmap --script smb-vuln* <target>Para qué sirve: Revisa múltiples CVEs en SMB de una sola pasada: MS08-067, MS17-010, MS10-061, etc.
-p 445 · devuelve VULNERABLE/SAFE por cada CVE encontrado
nmap --script ssl-heartbleed <target>Para qué sirve: Envía un heartbeat malformado y verifica si el servidor devuelve memoria sensible (CVE-2014-0160).
-p 443,8443 · si es vulnerable, muestra datos filtrados en hex
nmap --script http-shellshock <target>Para qué sirve: Inyecta `() { :; }; echo vulnerable` en headers User-Agent/Referer contra endpoints CGI.
-p 80,443 · --script-args http-shellshock.uri=/cgi-bin/test.cgi
nmap --script http-sql-injection <target>Para qué sirve: Crawlea la web e inyecta payloads SQL en parámetros GET/POST para detectar errores de base de datos.
-p 80,443 · --script-args httpspider.maxdepth=3
nmap --script smb-vuln-ms17-010 <target>Para qué sirve: Verifica si el target es vulnerable a EternalBlue (el exploit de WannaCry). Chequea si SMBv1 está habilitado y si el parche KB4013389 está ausente.
-p 445 · resultado: VULNERABLE / SAFE / UNKNOWN
nmap --script broadcast <target>Para qué sirve: Envía paquetes broadcast/multicast para descubrir servicios en la red local sin apuntar a IPs específicas.
--script broadcast-dhcp-discover obtiene IP del DHCP · broadcast-dns-service-discovery encuentra servicios mDNS
Scripts de información y enumeración (NSE)
nmap -sC <target>Para qué sirve: Corre los scripts de la categoría "default" — los considerados seguros y no intrusivos. Ideal como primer paso antes de escanear más a fondo.
-sC equivalente a --script default · no explota nada
nmap --script http-enum <target>Para qué sirve: Hace fuzzing de paths comunes (/admin, /login, /phpinfo, /backup, /.git) y reporta los que devuelven 200/403.
-p 80,443 · --script-args http-enum.basepath=/app/ path base
nmap --script dns-brute <target>Para qué sirve: Resuelve DNS contra una wordlist de subdominios (www, mail, ftp, dev, staging, etc.) para mapear la infraestructura.
-p 53 · --script-args dns-brute.threads=20 · dns-brute.hosts=wordlist.txt
nmap --script smb-enum-users <target>Para qué sirve: Extrae la lista de usuarios locales del target vía RPC/SMB sin necesidad de credenciales (si el target lo permite).
-p 445 · --script-args smbuser=,smbpass= si necesita auth
nmap --script smb-enum-shares <target>Para qué sirve: Lista todos los shares SMB y sus permisos de acceso (READ, WRITE, NONE). Útil para encontrar shares abiertos sin password.
-p 445 · muestra ADMIN$, C$, IPC$, print$, etc.
nmap --script snmp-sysdescr <target>Para qué sirve: Consulta la comunidad SNMP "public" (default) para obtener hostname, OS, uptime y descripción del dispositivo.
-sU -p 161 UDP · --script-args snmpcommunity=public
nmap --script http-headers <target>Para qué sirve: Hace un GET y muestra todos los headers de respuesta. Revela Server, X-Powered-By, X-Frame-Options, CSP, cookies sin secure/httpOnly.
-p 80,443
nmap --script ssl-cert <target>Para qué sirve: Descarga y parsea el certificado SSL/TLS del servidor. Muestra Common Name, SANs, fecha de expiración, algoritmo de firma y si es self-signed.
-p 443
Scripts de fuerza bruta (NSE)
nmap --script ftp-brute <target>Para qué sirve: Prueba credenciales contra el servicio FTP usando wordlists por defecto de Nmap. Si encuentra login válido, muestra los permisos del usuario.
-p 21 · --script-args userdb=/usr/share/wordlists/ftp-users.txt,passdb=rockyou.txt
nmap --script ssh-brute <target>Para qué sirve: Intenta loguearse por SSH con combinaciones user:pass. Lento pero útil si el target tiene contraseñas débiles.
-p 22 · --script-args brute.credfile=creds.txt archivo con user:pass por línea
nmap --script http-brute <target>Para qué sirve: Ataca formularios de login HTTP Basic o Digest authentication. Detecta el método de auth automáticamente.
-p 80,443 · --script-args http-brute.path=/admin/,http-brute.method=POST
nmap --script mysql-brute <target>Para qué sirve: Prueba credenciales MySQL. Por defecto intenta root:root, root:password, admin:admin antes de usar wordlists.
-p 3306 · --script-args mysqluser=root,mysqlpass=wordlist.txt
nmap --script smb-brute <target>Para qué sirve: Fuerza bruta contra autenticación SMB de Windows. Útil para encontrar cuentas locales con contraseñas débiles o sin password.
-p 445 · --script-args smbbasic=true,smbdomain=WORKGROUP
nmap --script pgsql-brute <target>Para qué sirve: Prueba credenciales PostgreSQL. Intenta primero el usuario default "postgres" sin password (configuración común en dev).
-p 5432 · --script-args pgsqluser=postgres,pgsqldb=template1
Formatos de salida (Nmap)
nmap -oN <archivo> <target>Para qué sirve: Output normal (texto legible).
-oN output.txt archivo normal
nmap -oX <archivo> <target>Para qué sirve: Output XML (para parsers).
-oX output.xml archivo XML
nmap -oG <archivo> <target>Para qué sirve: Output grepable (para grep/awk).
-oG output.gnmap archivo grepable
nmap -oA <base> <target>Para qué sirve: Output en todos los formatos.
-oA output genera .nmap .xml .gnmap
nmap --open <target>Para qué sirve: Mostrar solo puertos abiertos.
--open filtra closed/filtered
nmap -v <target>Para qué sirve: Output verboso.
-v verbose · -vv más verbose · -d debug
Opciones de output y utilidad (Nmap)
nmap --reason <target>Para qué sirve: Mostrar razón del estado del puerto.
--reason syn-ack, reset, etc.
nmap --packet-trace <target>Para qué sirve: Mostrar paquetes enviados/recibidos.
--packet-trace debug de red · muy verboso
nmap --iflistPara qué sirve: Listar interfaces y rutas disponibles.
--iflist sin target · muestra interfaces
nmap -e <interfaz> <target>Para qué sirve: Especificar interfaz de red.
-e eth0 interfaz · -e wlan0 WiFi
nmap -S <IP> <target>Para qué sirve: Spoofing de IP fuente.
-S 192.168.1.100 IP falsa · -e interfaz requerida
nmap -n / -R <target>Para qué sirve: Control de resolución DNS.
-n sin DNS · más rápido · -R siempre DNS
