Escaneo Básico

wpscan --url http://targetEscaneo básico del sitio
wpscan --url http://target --no-bannerNo mostrar banner
wpscan --url http://target -vVerbose mode
wpscan --url http://target --format cli-no-colourOutput sin colores

Output

wpscan --url http://target -o results.txtGuardar en archivo
wpscan --url http://target -o results.json --format jsonOutput JSON
wpscan --url http://target -o results.html --format cli-no-colourOutput legible

Enumaración

wpscan --url http://target -e vpPlugins vulnerables
wpscan --url http://target -e apTodos los plugins (no solo vuln)
wpscan --url http://target -e atTodos los themes
wpscan --url http://target -e uEnumerar usuarios
wpscan --url http://target -e ttTimthumbs
wpscan --url http://target -e mMedias (uploads públicos)

Enumeración Combinada

wpscan --url http://target -e vp,uPlugins vuln + usuarios
wpscan --url http://target -e ap,at,uTodos plugins + themes + users
wpscan --url http://target -e "vp,ap,u"Mismo con comillas

Modo Stealth

wpscan --url http://target --throttle=55 segundos entre requests
wpscan --url http://target --random-user-agentUser-Agent aleatorio
wpscan --url http://target --ruaShort para random-user-agent
wpscan --url http://target --max-threads=5Limitar hilos

Enumerar Usuarios

wpscan --url http://target -e uEnumerar usuarios (by default)
wpscan --url http://target -e u --detection-mode aggressiveDetección agresiva
wpscan --url http://target -e u --users-to-iterate "1,2,3"Iterar IDs específicos

IDs de Usuario

wp-json/wp/v2/usersAPI REST — enumerar usuarios
?author=1Author archive — redirige a /author/admin
?author=2Probar diferentes IDs

Diccionarios

--wordlist /usr/share/wordlists/rockyou.txtRockyou para brute force
--passwords users.txtArchivo con contraseñas

Plugins Vulnerables

wpscan --url http://target -e vpSolo plugins con vulnerabilidades conocidas
wpscan --url http://target -e vp --plugins-detection mixedDetección mixta (aggressive + passive)
wpscan --url http://target -e vp --plugins-version-detection aggressiveForzar detección de versión

Plugins Específicos

wpscan --url http://target -e vp --plugin-detection aggressiveDetectar todos los plugins instalados
wpscan --url http://target -e vp --wp-plugins-dir /wp-content/pluginsDirectorio custom de plugins

Enumeración de Plugins

wpscan --url http://target -e apTodos los plugins (no solo vuln)
wpscan --url http://target -e ap --plugins-detection aggressiveDetección agresiva de plugins
wpscan --url http://target -e ap --wp-content-dir /custom/pluginsDirectorio custom

Themes Vulnerables

wpscan --url http://target -e vtThemes con vulnerabilidades conocidas
wpscan --url http://target -e vt --themes-detection aggressiveDetección agresiva de themes

Enumeración de Themes

wpscan --url http://target -e atTodos los themes instalados
wpscan --url http://target -e at --themes-detection aggressiveDetección agresiva

Brute Force de Contraseñas

wpscan --url http://target --passwords users.txtBrute force con lista de usuarios
wpscan --url http://target --passwords users.txt --wordlist rockyou.txtBrute force con diccionario
wpscan --url http://target --passwords users.txt --threads=55 hilos para brute force
wpscan --url http://target --passwords users.txt --throttle=22 segundos entre intentos

Archivos de Usuario

echo -e "admin\neditor\nuser1" > users.txtCrear lista de usuarios
wpscan --url http://target -e u --format cli-no-colour > users.txtExportar usuarios encontrados

XML-RPC

wpscan --url http://target -e xmlrpcVerificar XML-RPC
xmlrpc.phpEndpoint XML-RPC
wp.getUsersBlogsMétodo para brute force
system.multicallMúltiples intentos en un solo request

Token de API WPScan

wpscan --api-token "TOKEN"Usar token de API para datos de vulns
--api-token (env var)Variable de entorno WPSCAN_API_TOKEN
wpscan --url http://target -e vp --api-token "TOKEN"Enum plugins con datos de vulns

Proxy

wpscan --url http://target --proxy "http://127.0.0.1:8080"Proxy HTTP
wpscan --url http://target --proxy "socks5://127.0.0.1:9050"Proxy SOCKS5 (Tor)
wpscan --url http://target --proxy "http://127.0.0.1:8080" --proxy-auth "user:pass"Proxy con autenticación

Opciones Varias

wpscan --url http://target --disable-tls-checksDeshabilitar verificación TLS
wpscan --url http://target --forceForzar escaneo (ignorar wpscan.yml)
wpscan --url http://target --wp-content-path /customDirectorio WP custom
wpscan --url http://target --wp-plugins-dir /pluginsDirectorio plugins custom
wpscan --url http://target --cookie-string "session=abc"Cookie para autenticación
