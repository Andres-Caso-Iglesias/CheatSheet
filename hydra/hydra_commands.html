Sintaxis básica (Hydra)
hydra -l <user> -p <pass> <host> <servicio>Para qué sirve: Prueba UN usuario y UNA contraseña contra un servicio. Útil para verificar credenciales específicas sin usar wordlists.
hydra -l admin -p admin 192.168.1.1 ssh
hydra -L <archivo> -P <archivo> <host> <servicio>Para qué sirve: Fuerza bruta con wordlists de usuarios y contraseñas. Prueba TODAS las combinaciones: cada usuario con cada contraseña. L pero mayúscula = archivo.
-L users.txt -P passwords.txt · combina todo
hydra -l <user> -P <archivo> <host> <servicio>Para qué sirve: Ataque de diccionario contra un usuario conocido. Prueba todas las contraseñas de la wordlist contra un solo usuario. Ideal cuando sabes el username.
-l root -P rockyou.txt · un usuario, muchas pass
hydra -L <archivo> -e ns <host> <servicio>Para qué sirve: Añade checks automáticos: n = null password (sin contraseña), s = same as username (contraseña = usuario). Captura credenciales triviales sin wordlist.
-e ns prueba vacío y user=pass · -e n solo null
hydra -C <archivo> <host> <servicio>Para qué sirve: Usa un archivo de combinaciones user:pass (una por línea, formato user:pass). No genera combinaciones — prueba exactamente lo que está en el archivo.
-C combos.txt · formato user:pass por línea
hydra -hPara qué sirve: Muestra ayuda completa con todos los servicios soportados, opciones y ejemplos. Útil para verificar qué protocolos están compilados en tu versión.
hydra -h · hydra -U <servicio> ayuda específica
Wordlists y diccionarios
/usr/share/wordlists/rockyou.txtPara qué sirve: La wordlist más famosa — 14 millones de contraseñas reales de la filtración de RockYou 2009. Incluida en Kali Linux. El punto de partida para cualquier ataque.
gzip -d /usr/share/wordlists/rockyou.txt.gz descomprimir
/usr/share/wordlists/seclists/Para qué sirve: Colección de Daniel Miessler con wordlists especializadas: passwords comunes, usernames, directorios web, fuzzing strings, patrones de URLs.
SecLists/Passwords/Common-Credentials/
cewl <url> -w custom.txtPara qué sirve: Genera una wordlist custom scrapeando palabras de una web. Extrae términos del sitio target para crear un diccionario contextualizado. Más efectivo que genéricas.
cewl https://target.com -w custom.txt -m 6
crunch <min> <max> <chars> -o output.txtPara qué sirve: Genera wordlists por fuerza bruta de patrones. Crea todas las combinaciones posibles de un set de caracteres. Útil cuando conoces el patrón de contraseñas.
crunch 6 8 0123456789 -o nums.txt
sort -u wordlist.txt -o clean.txtPara qué sirve: Elimina duplicados de una wordlist y la ordena. Reduce el tamaño del archivo y evita probar la misma contraseña múltiples veces innecesariamente.
sort -u unique · wc -l contar líneas
Servicios web (HTTP/HTTPS)
hydra -L users.txt -P pass.txt target http-get /loginPara qué sirve: Fuerza bruta de autenticación HTTP Basic. Envía credenciales en el header Authorization: Basic. El path es la URL protegida.
http-get método GET · /admin path protegido
hydra -L users.txt -P pass.txt target http-post-form "/login:user=^USER^&pass=^PASS^:F=incorrecto"Para qué sirve: Ataque a formulario web POST. ^USER^ y ^PASS^ se reemplazan con cada intento. F= indica la cadena que aparece cuando el login FALLA.
F=Login failed string de error · S=Welcome string de éxito
hydra -L users.txt -P pass.txt target http-get-form "/login:user=^USER^&pass=^PASS^:F=incorrecto"Para qué sirve: Igual que post-form pero para formularios GET. Los parámetros van en la URL. Menos común pero algunos formularios legacy usan GET para login.
http-get-form parámetros en URL
hydra -L users.txt -P pass.txt target https-post-form "/login:user=^USER^&pass=^PASS^:F=incorrecto"Para qué sirve: Igual que http-post-form pero sobre HTTPS. Usa el prefijo https- en lugar de http-. El resto de la sintaxis es idéntica.
https-post-form · https-get-form · SSL/TLS
hydra ... http-post-form "/login:^USER^:^PASS^:H=Cookie: session=abc:F=Error"Para qué sirve: Añade headers HTTP custom con H=. Necesario cuando el formulario requiere cookies de sesión, CSRF tokens o headers especiales para funcionar.
H=Cookie: session=xyz · H=Content-Type: application/json
Servicios de acceso remoto
hydra -L users.txt -P pass.txt target sshPara qué sirve: Fuerza bruta de SSH (puerto 22). Uno de los usos más comunes de Hydra. Lento por diseño — SSH limita conexiones concurrentes. Usar -t 4 o menos.
-t 4 4 hilos máximo · -s 2222 puerto custom
hydra -L users.txt -P pass.txt target ftpPara qué sirve: Fuerza bruta de FTP (puerto 21). Muchos servidores FTP permiten login anónimo — probar primero con anonymous:anonymous antes de atacar.
ftp · -s 2121 puerto custom
hydra -L users.txt -P pass.txt target telnetPara qué sirve: Fuerza bruta de Telnet (puerto 23). Texto plano sin cifrar — las credenciales viajan en claro. Común en routers, switches y dispositivos IoT antiguos.
telnet · -s 23 puerto
hydra -L users.txt -P pass.txt target rdpPara qué sirve: Fuerza bruta de Remote Desktop Protocol (puerto 3389). Requiere que Hydra esté compilado con soporte rdp. Lento y puede bloquear cuentas por políticas de Windows.
rdp · -s 3389 · cuidado con lockouts
hydra -L users.txt -P pass.txt target smbPara qué sirve: Fuerza bruta de SMB/Windows (puerto 445). Prueba credenciales contra autenticación Windows. Útil para encontrar cuentas locales con passwords débiles.
smb · -s 445
hydra -L users.txt -P pass.txt target vncPara qué sirve: Fuerza bruta de VNC (puerto 5900). VNC usa autenticación por contraseña simple (8 chars max en versiones antiguas). Spaceo de keyspace reducido.
vnc · -s 5900 · max 8 caracteres
Bases de datos
hydra -L users.txt -P pass.txt target mysqlPara qué sirve: Fuerza bruta de MySQL (puerto 3306). Muchos installs default tienen root sin password o con password trivial. Probar primero root:root.
mysql · -s 3306 · root:root default
hydra -L users.txt -P pass.txt target postgresPara qué sirve: Fuerza bruta de PostgreSQL (puerto 5432). El usuario default es postgres. En dev environments frecuentemente sin password.
postgres · -s 5432 · postgres:postgres default
hydra -L users.txt -P pass.txt target mssqlPara qué sirve: Fuerza bruta de Microsoft SQL Server (puerto 1433). El usuario sa es el admin por defecto. Muchas instalaciones legacy tienen sa con password vacío o débil.
mssql · -s 1433 · sa:sa default
hydra -L users.txt -P pass.txt target oracle-listenerPara qué sirve: Fuerza bruta del listener de Oracle (puerto 1521). Permite descubrir credenciales de base de datos Oracle. Requiere SID para conexión completa.
oracle-listener · -s 1521
Ataque a formularios web (avanzado)
hydra ... http-post-form "/login:username=^USER^&password=^PASS^&csrf=abc123:F=Invalid"Para qué sirve: Ataque a formulario con campo CSRF token estático. Si el token no cambia por sesión, puedes hardcodearlo. Si cambia, necesitas un approach diferente.
csrf=abc123 token fijo · si rota, usar otro método
hydra ... http-post-form "/login:username=^USER^&password=^PASS^:F=Invalid:H=Cookie: PHPSESSID=xyz"Para qué sirve: Inyecta cookie de sesión necesaria para el formulario. Algunos formularios rechazan peticiones sin sesión válida. Obtener la cookie primero con curl o browser.
H=Cookie: PHPSESSID=xyz sesión activa
hydra ... http-post-form "/login:username=^USER^&password=^PASS^:F=Invalid:S=Dashboard"Para qué sirve: Usa S= para definir la cadena de ÉXITO en lugar de F= de fallo. Hydra para cuando encuentra S= en la respuesta. Más preciso cuando hay múltiples mensajes de error.
S=Welcome éxito · F=Error fallo
hydra ... http-post-form "/api/login:{\"user\":\"^USER^\",\"pass\":\"^PASS^\"}:F=error:H=Content-Type: application/json"Para qué sirve: Ataque a APIs REST con JSON body. Las APIs modernas usan JSON en lugar de form-urlencoded. H= define el Content-Type correcto.
H=Content-Type: application/json · body JSON
hydra ... http-post-form "/login:user=^USER^&pass=^PASS^:F=Invalid:C=/path/to/cookie.txt"Para qué sirve: Usa archivo de cookies de Netscape (exportado del browser). Útil cuando necesitas cookies complejas con múltiples valores, HttpOnly, Secure flags.
C=cookies.txt archivo Netscape format
Opciones adicionales
hydra -v -V ...Para qué sirve: Modo verbose. -v muestra cada intento de login, -V muestra cada intento + la respuesta del servidor. Útil para debuggear por qué falla un ataque.
-v verbose · -V muy verbose · ver respuestas
hydra -o output.txt ...Para qué sirve: Guarda las credenciales encontradas en un archivo. Formato: [PORT][SERVICE] host: login:password. Útil para reportes y documentación del engagement.
-o results.txt · -O formato JSON
hydra -w <segundos> ...Para qué sirve: Timeout por intento en segundos. Útil para servicios lentos o con alta latencia. Si el servicio no responde en el tiempo, Hydra pasa al siguiente intento.
-w 10 10 segundos timeout · default 30s
hydra -f ...Para qué sirve: Exit tras encontrar la PRIMERA credencial válida. Por defecto Hydra sigue buscando todas las combinaciones. -f para cuando solo necesitas una entrada.
-f exit on first valid · ahorra tiempo
hydra -s <puerto> ...Para qué sirve: Especifica un puerto custom para el servicio. Necesario cuando el servicio corre en un puerto no estándar (SSH en 2222, HTTP en 8080, etc.).
-s 2222 SSH custom · -s 8080 HTTP alternative
Control de velocidad y concurrencia
hydra -t <hilos> ...Para qué sirve: Número de conexiones simultáneas por host. Default 16. Aumentar acelera el ataque pero puede saturar el target o disparar rate limiting. SSH requiere -t 4 o menos.
-t 4 SSH · -t 16 default · -t 64 agresivo
hydra -T <hilos> ...Para qué sirve: Número TOTAL de conexiones simultáneas across TODOS los hosts (cuando usas -M). Si tienes 10 hosts y -T 20, máximo 20 conexiones repartidas.
-T 32 32 conexiones totales · -M múltiples hosts
hydra -M <archivo> ...Para qué sirve: Ataque contra múltiples hosts simultáneamente. El archivo contiene una lista de IPs/hostnames (uno por línea). Hydra distribuye los intentos entre todos los targets.
-M targets.txt un host por línea
hydra -c <ms> ...Para qué sirve: Delay entre intentos en milisegundos. Útil para evadir rate limiting o IDS. Añade pausa entre cada intento de login. Más lento pero más stealth.
-c 500 500ms entre intentos · -c 1000 1 segundo
hydra -x <min>:<max>:<chars> ...Para qué sirve: Genera passwords al vuelo sin wordlist. Crea combinaciones de longitud min a max con los caracteres especificados. Útil cuando conoces el patrón de la política de passwords.
-x 3:5:a 3-5 chars, lowercase · -x 6:8:1 números
Recovery y evasión
hydra -RPara qué sirve: Resume un ataque anterior desde donde se quedó. Hydra guarda el estado en ~/.hydra.restore. Útil si se cortó la conexión o tuviste que parar el ataque.
hydra -R resume último session · sin otros args
hydra -S ...Para qué sirve: Usa SSL/TLS para la conexión. Necesario para servicios como https, imaps, pop3s, smtps. El servicio debe soportar SSL nativo (no STARTTLS).
-S SSL mode · imaps · pop3s
hydra -uPara qué sirve: Loop de usuarios — prueba cada usuario con TODAS las passwords antes de pasar al siguiente. Por defecto Hydra prueba cada password contra TODOS los usuarios. -u cambia el orden.
-u user-first · sin -u pass-first (default)
hydra -qPara qué sirve: Modo silencioso — no muestra output de intentos fallidos. Solo muestra credenciales válidas. Útil para scripts automatizados o cuando no quieres verbose en pantalla.
-q quiet · solo éxitos
hydra -4 / -6Para qué sirve: Fuerza IPv4 (-4) o IPv6 (-6) para la conexión. Necesario cuando el host tiene ambas resoluciones y quieres controlar cuál usar.
-4 solo IPv4 · -6 solo IPv6
