Comandos Windows

Referencia interactiva de comandos Windows CMD y PowerShell

← Volver al inicio
Navegación de directorios (CMD)
dirPara qué sirve: Lista el contenido de un directorio.
/w formato ancho · /p prefijo · /q silencioso · /a ocultos · /o orden · /t clasificación
cdPara qué sirve: Cambia al directorio especificado.
ruta ir a ruta · .. subir nivel · \ raíz · %CD% directorio actual
mdPara qué sirve: Crea directorios nuevos.
nombre crear directorio · /s crear padre si no existe
rd / rmdirPara qué sirve: Elimina directorios.
/s incluye subdirectorios · /q silencioso · nombre directorio a borrar
clsPara qué sirve: Limpia la pantalla de la consola. Sin parámetros.
Gestión de archivos (CMD)
copyPara qué sirve: Copia archivos.
origen destino copiar archivo · /y confirmar sobrescritura · /v verbose · /z en ZIP
movePara qué sirve: Mueve o renombra archivos.
origen destino mover/renombrar · /y confirmar sobrescritura
del / erasePara qué sirve: Elimina archivos.
archivo eliminar archivo · /p confirmar · /f forzar · /s silencioso
xcopyPara qué sirve: Copia archivos y árboles de directorios.
/s directorios vacíos · /e directorios y subdirectorios · /h archivos ocultos · /r recursivo
robocopyPara qué sirve: Copia robusta de archivos (reemplaza xcopy).
/s recursivo · /e todo · /mir espejo · /purge limpiar · /mt:n hilos
attribPara qué sirve: Muestra o cambia atributos de archivos.
+r/-r lectura · +h/-h oculto · +s/-s sistema · /s recursivo
Gestión de procesos (CMD)
tasklistPara qué sirve: Muestra procesos en ejecución.
/fi "filtro" filtrar · /fo formato table, list, csv · /nh sin cabecera · /v verbose
taskkillPara qué sirve: Mata procesos por PID o nombre.
/pid n por PID · /im nombre por nombre · /f forzar · /t terminar árbol
systeminfoPara qué sirve: Muestra información del sistema.
/s servidor remoto · /u usuario · /p clave
taskmgrPara qué sirve: Abre el Administrador de Tareas (GUI). Sin parámetros.
Red y conectividad (CMD)
ipconfigPara qué sirve: Muestra configuración de red.
/all toda la info · /release liberar DHCP · /renew renovar DHCP · /flushdns limpiar caché DNS
pingPara qué sirve: Verifica conectividad enviando paquetes ICMP.
-n n nº paquetes · -l n tamaño búfer · -i n TTL · -4 IPv4 · -6 IPv6
tracertPara qué sirve: Muestra la ruta que toman los paquetes.
-d no resolver DNS · -h n máximo saltos · -w n espera ms
netstatPara qué sirve: Muestra conexiones de red y puertos.
-a todas · -b estadísticas · -n numérico · -o procesos · -r rutas
arpPara qué sirve: Muestra o modifica tabla ARP.
-a toda la tabla · -d eliminar entrada · -s añadir entrada
nslookupPara qué sirve: Consulta servidores DNS.
nombre buscar dominio · servidor servidor DNS especifico
net viewPara qué sirve: Muestra equipos en el dominio o grupo de trabajo.
\\computadora ver recursos · /domain dominio
net usePara qué sirve: Conecta o desconecta de recursos compartidos.
letra: \\servidor\recurso mapear unidad · /delete desconectar · /persistent:yes persistente
Gestión de usuarios y grupos (CMD)
net userPara qué sirve: Gestiona cuentas de usuario.
nombre ver usuario · /add crear · /delete eliminar · /active:yes/no activar/desactivar
net localgroupPara qué sirve: Gestiona grupos locales.
nombre ver grupo · /add crear · /delete eliminar · usuario /add añadir usuario
net accountsPara qué sirve: Configura políticas de cuentas.
/forcelogoff:time tiempo desconexión · /minpwlen:n longitud mínima · /maxpwage:n caducidad
net sharePara qué sirve: Gestiona recursos compartidos.
nombre=ruta crear · /delete eliminar · nombre ver
net sessionPara qué sirve: Lista o desconecta sesiones.
/delete desconectar · \\computadora sesiones de equipo
net start/stopPara qué sirve: Inicia o detiene servicios.
servicio nombre del servicio · net pause pausar · net continue reanudar
Navegación de directorios (PowerShell)
Get-ChildItem (ls, dir)Para qué sirve: Lista el contenido de un directorio.
-Recurse recursivo · -Hidden ocultos · -Name solo nombres · -File solo archivos · -Directory solo directorios
Set-Location (cd)Para qué sirve: Cambia al directorio especificado.
ruta ir a ruta · .. subir nivel · \ raíz · -PassThru mostrar ubicación
New-Item (md)Para qué sirve: Crea directorios o archivos nuevos.
-ItemType Directory/File · -Name nombre · -Path ruta
Remove-Item (rd, del)Para qué sirve: Elimina archivos o directorios.
-Recurse recursivo · -Force forzar · -Confirm confirmar
Clear-Host (cls)Para qué sirve: Limpia la pantalla de la consola. Sin parámetros.
Gestión de archivos (PowerShell)
Copy-Item (copy)Para qué sirve: Copia archivos o directorios.
-Destination destino · -Recurse recursivo · -Force sobrescribir · -PassThru mostrar
Move-Item (move)Para qué sirve: Mueve archivos o directorios.
-Destination destino · -Force sobrescribir · -PassThru mostrar
Get-Content (cat, type)Para qué sirve: Muestra el contenido de un archivo.
-TotalCount n n líneas · -Tail n últimas n · -Delimiter delimitador
Set-ContentPara qué sirve: Escribe contenido en un archivo (sobrescribe).
-Value contenido · -Path archivo · -Force forzar
Select-String (grep)Para qué sirve: Busca patrones en archivos.
-Pattern expresión · -Path archivo · -CaseSensitive · -Context n líneas contexto
Out-FilePara qué sirve: Redirige salida a un archivo.
-FilePath archivo · -Append añadir · -Encoding codificación
Gestión de procesos (PowerShell)
Get-Process (ps, gps)Para qué sirve: Muestra procesos en ejecución.
-Name nombre filtrar por nombre · -Id PID filtrar por PID · -IncludeUserName con usuario
Stop-Process (kill, spps)Para qué sirve: Mata procesos por nombre o PID.
-Name nombre por nombre · -Id PID por PID · -Force forzar
Get-Service (gsv)Para qué sirve: Muestra servicios del sistema.
-Name nombre filtrar · -DependentServices dependencias · -RequiredServices requeridos
Start-ServicePara qué sirve: Inicia un servicio.
-Name nombre servicio · -PassThru mostrar
Stop-ServicePara qué sirve: Detiene un servicio.
-Name nombre servicio · -Force forzar
Red y conectividad (PowerShell)
Test-Connection (ping, tnc)Para qué sirve: Verifica conectividad de red (ICMP y TCP).
-TargetName destino · -Ping ICMP · -TcpPort n puerto TCP · -Count n paquetes
Get-NetIPAddressPara qué sirve: Muestra direcciones IP.
-InterfaceAlias interfaz · -AddressFamily IPv4/IPv6 · -IncludeAllCompartments
Get-NetRoutePara qué sirve: Muestra tabla de enrutamiento.
-InterfaceAlias interfaz · -DestinationPrefix destino · -NextHop siguiente salto
Get-NetAdapterPara qué sirve: Muestra adaptadores de red.
-Name nombre filtrar · -InterfaceDescription descripción · -Physical solo físicos
Resolve-DnsName (nslookup)Para qué sirve: Consulta registros DNS.
-Name dominio dominio · -Server servidor DNS especifico · -Type tipo registro
