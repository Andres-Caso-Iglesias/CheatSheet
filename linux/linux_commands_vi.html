Navegación de directorios
pwdPara qué sirve: Muestra el directorio de trabajo actual (Print Working Directory). Sin parámetros.
lsPara qué sirve: Lista el contenido de un directorio.
-l lista larga · -a ocultos · -h tamaño legible · -R recursivo · -t orden por fecha · -S orden por tamaño · -r invertir orden · -1 una por línea
cdPara qué sirve: Cambia al directorio especificado.
ruta ir a ruta · ~ home · .. subir nivel · - directorio anterior
treePara qué sirve: Muestra la estructura de directorios en forma de árbol.
-L n niveles de profundidad · -a ocultos · -d solo dirs · -f ruta completa
duPara qué sirve: Estima el espacio en disco usado por archivos.
-h legible · -s resumen · -d n profundidad · --max-depth=n máx profundidad
dfPara qué sirve: Muestra el espacio disponible en disco.
-h legible · -T tipo FS · -i inodos · --total total al final
Gestión de archivos y directorios
cpPara qué sirve: Copia archivos y directorios.
-r recursivo · -p preservar atributos · -v verbose · -i confirmar sobrescribir · -u solo si más nuevo · -a archivo (equiv. -dpr)
mvPara qué sirve: Mueve o renombra archivos.
-i confirmar · -v verbose · -u solo si más nuevo · -b backup antes
rmPara qué sirve: Elimina archivos o directorios.
-r recursivo · -f forzar · -i confirmar · -v verbose · -d dirs vacíos
mkdirPara qué sirve: Crea directorios nuevos.
-p crear padres · -v verbose · -m 755 permisos al crear
rmdirPara qué sirve: Elimina directorios vacíos.
-p elimina padres vacíos · -v verbose
touchPara qué sirve: Crea archivos vacíos o actualiza timestamps.
-a solo acceso · -m solo modificación · -t timestamp personalizado · -r ref desde otro archivo
lnPara qué sirve: Crea enlaces entre archivos.
-s enlace simbólico · -f forzar · -v verbose · -r relativo
findPara qué sirve: Busca archivos en el sistema de archivos.
-name por nombre · -type f/d archivo/dir · -size tamaño · -mtime modificación · -exec ejecutar · -iname sin distinción · -maxdepth profundidad
locatePara qué sirve: Busca archivos por nombre rápidamente (usa base de datos).
-i sin distinción · -c contar · -l n limitar resultados · -r regex
statPara qué sirve: Muestra información detallada de archivos.
-f info sistema ficheros · -c formato formato personalizado · -t terse
filePara qué sirve: Determina el tipo de un archivo.
-b sin nombre · -i tipo MIME · -z comprimidos · -L seguir symlinks
Permisos y propietarios
chmodPara qué sirve: Cambia permisos de archivos/directorios.
-R recursivo · u/g/o/a usuario/grupo/otros/todos · +/-/= añadir/quitar/asignar · r/w/x lectura/escritura/ejecución · 755 octal
chownPara qué sirve: Cambia propietario y grupo de archivos.
-R recursivo · -v verbose · usuario:grupo asignar ambos · --from solo si coincide actual
chgrpPara qué sirve: Cambia el grupo propietario de archivos.
-R recursivo · -v verbose · --reference copiar grupo de otro archivo
umaskPara qué sirve: Define máscara de permisos para archivos nuevos.
-S formato simbólico · valor en octal para establecer máscara
sudoPara qué sirve: Ejecuta comandos con privilegios de superusuario.
-u usuario como otro usuario · -i shell interactivo root · -s shell actual como root · -l listar permisos · -k invalidar caché
suPara qué sirve: Cambia de usuario (por defecto a root).
- entorno limpio · -c "cmd" ejecutar comando · -s shell shell específico
passwdPara qué sirve: Cambia contraseñas de usuario.
-l bloquear cuenta · -u desbloquear · -d borrar contraseña · -e expirar
idPara qué sirve: Muestra UID, GID y grupos del usuario.
-u UID · -g GID · -G todos los grupos · -n nombre en vez de número
groupsPara qué sirve: Muestra los grupos a los que pertenece un usuario. Sin parámetros (muestra grupos del usuario actual). Acepta nombre de usuario como argumento.
who / wPara qué sirve: Muestra usuarios conectados al sistema.
-a toda la info · -b último arranque · -q solo nombres · -H cabeceras
Gestión de procesos
psPara qué sirve: Muestra procesos en ejecución.
aux todos los procesos · -e todos · -f completo · -u usuario filtrar usuario · --forest árbol de procesos
topPara qué sirve: Monitoriza procesos en tiempo real.
-d seg intervalo · -u usuario filtrar · -p PID proceso concreto · -n n iteraciones y salir
htopPara qué sirve: Monitor de procesos interactivo (mejorado).
-u usuario filtrar · -d décimas intervalo · -p PID monitorizar PID
killPara qué sirve: Envía señales a procesos (por defecto termina).
-9 SIGKILL forzado · -15 SIGTERM graceful · -l listar señales · -s señal señal por nombre
killallPara qué sirve: Mata procesos por nombre.
-9 forzado · -i confirmar · -u usuario solo ese usuario · -r regex
jobsPara qué sirve: Lista trabajos en segundo plano.
-l con PID · -p solo PID · -r solo en ejecución · -s solo detenidos
bg / fgPara qué sirve: Ejecuta trabajos en background (bg) o foreground (fg).
%n número de job · %nombre por nombre de comando
nohupPara qué sirve: Ejecuta comandos inmunes a desconexión.
comando & ejecutar en background sin colgar · redirige a nohup.out por defecto
nicePara qué sirve: Ejecuta procesos con prioridad ajustada.
-n valor prioridad -20 (max) a 19 (min)
renicePara qué sirve: Cambia prioridad de procesos en ejecución.
-n valor nueva prioridad · -p PID · -u usuario
systemctlPara qué sirve: Controla el sistema systemd (servicios, unidades).
start/stop/restart · enable/disable · status · list-units · --now
Red y conectividad
ipPara qué sirve: Configura y muestra interfaces de red (reemplaza ifconfig).
addr interfaces · route rutas · link dispositivos · -4/-6 IPv4/IPv6 · -s estadísticas
pingPara qué sirve: Verifica conectividad de red enviando paquetes ICMP.
-c n nº de paquetes · -i seg intervalo · -s bytes tamaño · -t ttl · -6 IPv6
curlPara qué sirve: Transfiere datos con URLs (HTTP, FTP, etc).
-O guardar archivo · -o nombre nombre personalizado · -L seguir redirecciones · -I solo cabeceras · -X método HTTP · -H cabecera · -d datos POST · -u user:pass auth
wgetPara qué sirve: Descarga archivos de la web (no interactivo).
-O nombre nombre salida · -r recursivo · -q silencioso · -c continuar descarga · --limit-rate limitar velocidad
sshPara qué sirve: Conexión segura remota mediante protocolo SSH.
-p puerto · -i clave clave privada · -L túnel local · -R túnel remoto · -v verbose · -N sin shell
scpPara qué sirve: Copia archivos de forma segura entre equipos (SSH).
-r recursivo · -P puerto · -i clave · -v verbose · -C compresión
netstatPara qué sirve: Muestra conexiones de red, tablas de enrutamiento.
-t TCP · -u UDP · -l escuchando · -n numérico · -p con proceso · -r rutas
ssPara qué sirve: Muestra conexiones de socket (reemplaza netstat).
-t TCP · -u UDP · -l escuchando · -n numérico · -p con proceso · -a todos
nmapPara qué sirve: Escanea puertos y descubre servicios de red.
-p puertos · -sV versión · -O SO · -A agresivo · -sn ping scan · -v verbose
traceroutePara qué sirve: Muestra la ruta que toman los paquetes hasta el destino.
-n numérico · -I ICMP · -T TCP · -p puerto · -m saltos
Manipulación de texto
catPara qué sirve: Muestra el contenido de archivos por pantalla.
-n numerar líneas · -b numerar no vacías · -A mostrar especiales · -s reducir líneas vacías
lessPara qué sirve: Visor de texto página por página (mejor que more).
-N números de línea · -S no ajustar líneas · -i búsqueda sin distinción · +G ir al final
headPara qué sirve: Muestra las primeras líneas de un archivo.
-n N primeras N líneas · -c N primeros N bytes · -q sin cabeceras
tailPara qué sirve: Muestra las últimas líneas de un archivo.
-n N últimas N líneas · -f seguir en tiempo real · -c N últimos N bytes · -F seguir aunque rote
grepPara qué sirve: Busca patrones de texto en archivos.
-i sin distinción · -r recursivo · -n nº línea · -v invertir · -c contar · -l solo archivos · -E regex extendida · -A/-B/-C n contexto
sedPara qué sirve: Editor de flujo para transformar texto.
-i editar en sitio · -n silencioso · -e expresión · -r regex extendida · s/a/b/g sustituir
awkPara qué sirve: Procesa y analiza patrones en texto (lenguaje).
-F sep separador · -v var=val variable · -f archivo script · {print $N} campo N
sortPara qué sirve: Ordena líneas de texto alfabética o numéricamente.
-n numérico · -r invertir · -k N campo N · -t sep separador · -u únicos · -h tamaños legibles
uniqPara qué sirve: Reporta u omite líneas repetidas adyacentes.
-c contar · -d solo duplicados · -u solo únicos · -i sin distinción
cutPara qué sirve: Extrae secciones de cada línea de un archivo.
-d sep delimitador · -f N campo N · -c N carácter N · --complement invertir selección
wcPara qué sirve: Cuenta líneas, palabras y bytes en archivos.
-l líneas · -w palabras · -c bytes · -m caracteres · -L línea más larga
diffPara qué sirve: Compara archivos línea por línea.
-u formato unificado · -r recursivo · -i sin distinción · -y lado a lado · -q solo si difieren
trPara qué sirve: Traduce o elimina caracteres en el flujo de entrada.
-d borrar caracteres · -s comprimir repetidos · -c complemento · [:upper:] clase de caracteres
teePara qué sirve: Lee de entrada y escribe a archivo y pantalla.
-a añadir en vez de sobreescribir · -i ignorar interrupciones
Forense y Esteganografía
stringsPara qué sirve: Busca y extrae cadenas de texto legibles dentro de archivos binarios.
-n N longitud mínima de N caracteres · -e especificar codificación · -a escanear todo el archivo
exiftoolPara qué sirve: Lee, escribe y manipula metadatos en una gran variedad de archivos (imágenes, PDFs, etc).
archivo muestra todos los metadatos · -all= elimina todos los metadatos · -Tag=valor modifica un tag
binwalkPara qué sirve: Analiza, extrae y hace ingeniería inversa a imágenes o archivos binarios buscando archivos ocultos.
-e extraer archivos automáticamente · -B buscar firmas · -M escaneo recursivo
steghidePara qué sirve: Oculta o extrae datos dentro de imágenes (JPEG, BMP) o archivos de audio (WAV, AU).
embed -cf img.jpg -ef sec.txt ocultar · extract -sf img.jpg extraer · info img.jpg mostrar info
stegseekPara qué sirve: Herramienta rápida para romper esteganografía de steghide mediante fuerza bruta.
archivo.jpg wordlist.txt fuerza bruta con diccionario · --seed usar semillas precalculadas
md5sumPara qué sirve: Calcula y verifica el hash MD5 de un archivo (comprobar integridad).
archivo calcula el hash · -c hashes.txt verifica hashes contra los archivos locales
