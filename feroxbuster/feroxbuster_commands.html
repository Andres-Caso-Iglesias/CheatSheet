Escaneo Básico
feroxbuster -u http://targetPara qué sirve: Escaneo básico de directorios en el target.
-u URL objetivo

-w wordlist a usar
feroxbuster -u http://target -t 50Para qué sirve: 50 hilos simultáneos.
-t threads
feroxbuster -u http://target --silentPara qué sirve: Solo output de resultados.
--silent modo silencioso
feroxbuster -u http://target -vPara qué sirve: Verbose mode.
-v verbose
feroxbuster -u http://target -vvPara qué sirve: Double verbose.
-vv double verbose
Output
feroxbuster -u http://target -o results.txtPara qué sirve: Guardar en archivo.
-o archivo de salida
feroxbuster -u http://target --jsonPara qué sirve: Output JSON.
--json formato JSON
feroxbuster -u http://target --json -o results.jsonPara qué sirve: JSON a archivo.
--json -o JSON guardado
feroxbuster -u http://target --debug-log debug.logPara qué sirve: Debug log.
--debug-log archivo de debug

--methods método HTTP
feroxbuster -u http://target --methods GET,POSTPara qué sirve: GET y POST.
--methods múltiples métodos
feroxbuster -u http://target --methods POSTPara qué sirve: Solo POST.
--methods POST solo POST
feroxbuster -u http://target -m PUT,DELETEPara qué sirve: PUT y DELETE.
-m alias de --methods

-s match status

--filter-status excluir status
feroxbuster -u http://target --filter-status 403,404Para qué sirve: Filtrar 403 y 404.
--filter-status múltiples valores
