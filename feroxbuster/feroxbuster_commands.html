Escaneo Básico

feroxbuster -u http://targetEscaneo básico de directorios
feroxbuster -u http://target -w /usr/share/wordlists/dirb/common.txtCon wordlist específica
feroxbuster -u http://target -t 5050 hilos
feroxbuster -u http://target --silentSolo output de resultados
feroxbuster -u http://target -vVerbose mode
feroxbuster -u http://target -vvDouble verbose

Output

feroxbuster -u http://target -o results.txtGuardar en archivo
feroxbuster -u http://target --jsonOutput JSON
feroxbuster -u http://target --json -o results.jsonJSON a archivo
feroxbuster -u http://target --debug-log debug.logDebug log

Métodos HTTP

feroxbuster -u http://target --methods GETSolo GET (default)
feroxbuster -u http://target --methods GET,POSTGET y POST
feroxbuster -u http://target --methods POSTSolo POST
feroxbuster -u http://target -m PUT,DELETEPUT y DELETE

Extensiones

feroxbuster -u http://target -x php,html,txtProbar con extensiones
feroxbuster -u http://target -x php,bak,old,zipExtensiones de backup
feroxbuster -u http://target -x asp,aspx,jspExtensiones Windows/Java

Filtros por Status

feroxbuster -u http://target -s 200,301,302Solo mostrar estos status
feroxbuster -u http://target --filter-status 404Filtrar 404
feroxbuster -u http://target --filter-status 403,404Filtrar 403 y 404
feroxbuster -u http://target -s 200 --filter-status 404Mostrar 200, filtrar 404

Filtros por Tamaño

feroxbuster -u http://target --filter-size 4523Filtrar por tamaño exacto
feroxbuster -u http://target --filter-regex "Not Found"Filtrar por regex
feroxbuster -u http://target --filter-wordcount 1234Filtrar por número de palabras
feroxbuster -u http://target --filter-linecount 45Filtrar por número de líneas

Regex Filters

feroxbuster -u http://target --filter-regex "error|forbidden"Múltiples patrones regex
feroxbuster -u http://target --filter-regex "404"Filtrar contenido 404
feroxbuster -u http://target -C "Not Found"Filtrar cadena exacta

Custom Headers

feroxbuster -u http://target -H "Authorization: Bearer token"Auth header
feroxbuster -u http://target -H "Cookie: session=abc123"Cookie header
feroxbuster -u http://target -H "X-Forwarded-For: 127.0.0.1"Custom header

Proxy

feroxbuster -u http://target --proxy http://127.0.0.1:8080Proxy HTTP
feroxbuster -u http://target --proxy socks5://127.0.0.1:9050Proxy SOCKS5 (Tor)

Autenticación

feroxbuster -u http://target --basic-auth user:passBasic Auth
feroxbuster -u http://target --cookie "session=abc123"Cookie para auth

Otras Opciones

feroxbuster -u http://target --user-agent "Mozilla/5.0"Custom User-Agent
feroxbuster -u http://target --delay 11 segundo entre requests
feroxbuster -u http://target --timeout 10Timeout de 10 segundos
feroxbuster -u http://target --dont-filterNo aplicar filtros automáticos
feroxbuster -u http://target --no-recursionNo recusar directorios
feroxbuster -u http://target --insecureNo verificar TLS/SSL

Recursión

feroxbuster -u http://target -rHabilitar recursión
feroxbuster -u http://target --recursiveMismo que -r
feroxbuster -u http://target -r -eRecursión + extraer links

Control de Profundidad

feroxbuster -u http://target -r --depth 3Max 3 niveles de recursión
feroxbuster -u http://target -r --force-recursionForzar recursión (ignorar filters)
feroxbuster -u http://target -r -C "Not Found"Filtrar en recursión

Uso de Wordlists

feroxbuster -u http://target -w /path/to/wordlist.txtWordlist personalizada
feroxbuster -u http://target -w common.txt -x phpWordlist + extensiones
feroxbuster -u http://target --default-wordlist /usr/share/wordlists/dirb/common.txtDefault wordlist config
