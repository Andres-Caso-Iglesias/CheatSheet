Escaneo Básico
sqlmap -u "URL"Para qué sirve: Detección automática de inyección en URL.
-u URL objetivo
sqlmap -u "URL" --batchPara qué sirve: Modo automático (no interactivo).
--batch auto-respuestas
sqlmap -u "URL" -v 0Para qué sirve: Verbose 0 — solo resultados.
-v 0 verbosity mínimo
sqlmap -u "URL" --bannerPara qué sirve: Obtener banner de la BD.
--banner versión DBMS
sqlmap -u "URL" --current-dbPara qué sirve: Nombre de la BD actual.
--current-db base de datos actual
sqlmap -u "URL" --current-userPara qué sirve: Usuario actual de la BD.
--current-user usuario actual
sqlmap -u "URL" --is-dbaPara qué sirve: Verificar si el usuario es DBA.
--is-dba privilegios de admin
sqlmap -u "URL" --dbsPara qué sirve: Listar todas las bases de datos.
--dbs listar BDs
Nivel y Riesgo
sqlmap -u "URL" --level=5Para qué sirve: Nivel de prueba máximo (1-5).
--level nivel de prueba
sqlmap -u "URL" --risk=3Para qué sirve: Riesgo máximo (1-3) — incluye OR-based.
--risk nivel de riesgo
sqlmap -u "URL" --level=5 --risk=3Para qué sirve: Cobertura máxima.
--level=5 --risk=3 máxima cobertura

sqlmap -u "URL" --randomize="id"Para qué sirve: Randomizar valor del parámetro.
--randomize valor aleatorio
