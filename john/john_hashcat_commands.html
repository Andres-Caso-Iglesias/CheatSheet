Hashcat Básico

hashcat -m 0 hashfile.txt rockyou.txtMD5 (mode 0)
hashcat -m 1000 hashfile.txt rockyou.txtNTLM (mode 1000)
hashcat -m 1800 hashfile.txt rockyou.txtSHA-512 Unix (mode 1800)
hashcat -m 3200 hashfile.txt rockyou.txtBCrypt (mode 3200)
hashcat --showMostrar hashes crackeados
hashcat -m 0 --show hashfile.txtMostrar con formato específico

Modos Comunes

0 = MD5MD5
100 = SHA1SHA1
1400 = SHA-256SHA-256
1000 = NTLMWindows NTLM
1800 = sha512cryptSHA-512 Unix
3200 = bcryptBCrypt
5600 = NetNTLMv2NetNTLMv2
9600 = MS-SQLMS-SQL NTLM
2612 = PHPSPHP md5($pass.$salt)

Attack Modes

hashcat -a 0 -m 0 hash.txt rockyou.txtDict attack (default)
hashcat -a 1 -m 0 hash.txt rock1.txt rock2.txtCombination attack
hashcat -a 3 -m 0 hash.txt ?a?a?a?a?a?aBrute force (mask)
hashcat -a 6 -m 0 hash.txt rock1.txt ?a?a?aHybrid wordlist + mask
hashcat -a 7 -m 0 hash.txt ?a?a?a rock1.txtHybrid mask + wordlist

hashcat -m 0 --force hash.txt rockyou.txtForce (ignorar warnings)
hashcat -m 0 --statusEnable status screen
hashcat -m 0 -j '$-$-$-$-$' hash.txt rockyou.txtLeft rule (wordlist rules)
hashcat -m 0 -k '$-$-$-$-$' hash.txt rockyou.txtRight rule

Mask Placeholders

?l = lowercase (a-z)Letras minúsculas
?u = uppercase (A-Z)Letras mayúsculas
?d = digit (0-9)Dígitos
?s = special (!@#$...)Caracteres especiales
?a = all (?l?u?d?s)Todos los caracteres
?b = 0x00-0xffTodos los bytes

Ejemplos de Masks

hashcat -a 3 -m 0 hash.txt ?l?l?l?l?l?l?l7 minúsculas
hashcat -a 3 -m 0 hash.txt ?u?l?l?l?l?d?d1 mayúscula + 4 min + 2 dígitos
hashcat -a 3 -m 0 hash.txt ?a?a?a?a?a?a?a?a8 all (lento)
